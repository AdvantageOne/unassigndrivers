Add a service account to your database

A service account is a dedicated MyGeotab user that Advantage One's scheduler signs in with. Once it's in place, your schedule runs automatically at the time you set, even when nobody has MyGeotab open.

  1. Open the Users page. In MyGeotab, go to People → Users (or Administration → Users) and click Add.
  2. Set the user name to svc-unassign. Give it a strong password. For the first and last name, use something clear like Service / Unassign, and leave Driver turned off.
  3. Set the security clearance to Administrator. The scheduler needs this to change driver assignments and to read and save the schedule.
  4. Set the groups (data access) to Company Group. This gives the account access to every asset, so the schedule can reach your whole fleet or any group you pick on the Scheduler tab.
  5. Save the user, then send us the details securely. Share the user name and password with Advantage One by phone or another secure method, not plain email. We'll link your database to the scheduler and confirm it's working.
Keep the account as it is. Don't use svc-unassign for everyday sign-ins. If you change its password, clearance or groups, or delete it, scheduled runs will stop. Let us know first so we can update the scheduler.
